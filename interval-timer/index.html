Interval timer for PE and HIIT

Set work and rest times, the number of rounds and an optional warm-up and cool-down. Beeps and spoken cues tell everyone when to go and when to rest.

Keyboard: Space start/pause · S skip · R reset · F full screen.

Interval timer presets

  • Tabata – 20 seconds hard work, 10 seconds rest, 8 rounds (4 minutes).
  • HIIT 30/30 and 40/20 – classic high-intensity intervals with a warm-up and cool-down.
  • PE circuit – 45 seconds at each station with 15 seconds to move on.
  • Class stations – 5 minutes per station with 30 seconds to swap, for carousel activities in any subject.

The screen turns green for work, blue for rest, yellow for the warm-up and purple for the cool-down, so everyone can see what to do from across the hall. Three short beeps count down the last seconds of each part.

Questions

Can I use it for my own workouts?

Of course – it works just as well for home workouts, running intervals and gym sessions as for PE lessons.

Does it work with the screen locked?

Keep the page open: the timer keeps the screen awake on supported devices. Sounds and spoken cues need the page to be open.
