Multiple timers

Run a separate countdown for each group, table or station. Name them, set different times, and start them together or one by one.

Tap a timer’s name to rename it, or its numbers to change the time. Up to 12 timers. F = full screen.

Ideas for multiple timers

  • A different time for each group in a carousel or rotation.
  • Staggered starts for practical experiments.
  • Timing several presentations or debates.
  • Kitchen timers in food technology.
